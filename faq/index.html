常见问题 ​

API 中转和手机远程控制有什么区别？ ​

API 中转解决的是“让 Codex 通过统一 API 地址发送请求”；手机远程控制解决的是“离开电脑后继续从手机操作本地运行的 Codex”。两者可以分别使用，也可以组合使用：被控电脑上的 Codex 可以使用 API 中转配置。

Codex 和文件在哪里运行？ ​

API 中转会转发 Codex 请求，具体请求内容取决于客户端和当前服务配置。手机远程控制的命令、文件和终端操作发生在你的电脑上，手机只负责发送操作和显示结果。

为什么必须从“使用密钥”复制配置？ ​

控制台生成的配置会根据当前分组和认证模式输出正确组合，比复制旧教程更可靠。配置入口在 API 密钥列表的 使用密钥。

API Key 可以多人共用吗？ ​

不建议。为每台设备或每个项目创建独立密钥，便于限制额度、轮换凭据和定位用量。

电脑端关闭后还能从手机操作吗？ ​

不能。电脑需要开机联网，电脑端也必须保持运行。

如何移除一台电脑？ ​

进入设备列表，找到这台电脑并移除，然后退出电脑端。
