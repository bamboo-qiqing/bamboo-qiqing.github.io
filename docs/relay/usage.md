# 用量与额度

## 仪表盘

仪表盘适合快速确认余额、今日请求、Token、实际消费和最近使用时间。数字有延迟时，先刷新页面并确认时间范围。

## 使用记录

在使用记录中按以下字段缩小范围：

1. 请求发生时间。
2. API Key 名称或末四位。
3. 分组和模型。
4. 请求状态码。
5. 输入、输出和缓存 Token。

不要只用“今天失败了”描述问题。时间、模型和状态码通常是区分配置错误、额度问题和上游异常所需的最小信息。

## 常见状态

- **额度耗尽**：检查密钥额度、时间窗口和账户余额。
- **请求数增加但余额未变**：等待统计同步，再查看实际扣费字段。
- **模型不可选**：当前分组没有该模型，不能仅靠修改客户端模型名解决。
- **延迟升高**：比较同一时间范围的分组和模型，不要把单次慢请求当作整体故障。

## 诊断信息模板

反馈问题时可以提供：

```text
发生时间（含时区）：
客户端：Codex CLI / Codex Desktop
操作系统：
分组：
模型：
API Key 末四位：
状态码：
错误消息：
是否能访问控制台：
```

请删除完整 API Key、账号邮箱、工作区路径和请求正文中的业务数据。
