# 快速开始

完成一次最小配置只需要：一个可登录的服务账号、一个已分配 Codex 分组的 API Key，以及本机已经安装好的 Codex CLI 或 Desktop。

## 1. 登录服务

打开管理员提供的服务地址：

```text
<SUB2API_SERVICE_URL>
```

登录后进入用户控制台。服务地址和账号由服务管理员提供，本文档不公开实际入口。

## 2. 创建 API Key

进入 **API Key** 页面：

1. 点击 **创建密钥**。
2. 填写便于识别的名称，例如 `codex-main`。
3. 选择一个可用于 Codex 的分组。
4. 根据需要设置有效期、额度或 IP 限制。
5. 保存后立即复制密钥。

如果密钥没有分组，使用密钥弹窗不会生成可用配置。回到密钥列表，点击分组列完成分配。

## 3. 复制 Codex 配置

打开该密钥的 **使用密钥** 操作，选择 **Codex CLI**。按照当前系统选择 macOS/Linux 或 Windows 标签，复制弹窗生成的配置文件和环境变量。

不要手动把服务地址拼成其他路径。弹窗生成的 `base_url`、认证模式和配置文件组合已经根据当前分组能力处理好。

## 4. 重启 Codex

保存配置后完全退出 Codex CLI 或 Desktop，再重新打开并新建任务。Desktop/API Key Mode 可能需要完整退出后再启动，单纯切换窗口不会重新加载工具注册表。

## 5. 完成验证

用一个低成本的小任务验证：

```text
请回复“连接成功”，不要读取或修改任何文件。
```

如果请求成功，进入 [用量与额度](/relay/usage) 确认出现一条请求记录。如果失败，记录时间、模型、状态码和密钥末四位，再查看[故障排查](/relay/troubleshooting)。

::: warning 不要分享配置文件
`auth.json`、`config.toml`、Shell 配置文件和环境变量中可能包含完整 API Key。提交工单前请删除密钥值，只保留变量名、服务地址路径和错误信息。
:::
