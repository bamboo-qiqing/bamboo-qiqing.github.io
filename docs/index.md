<p class="doc-intro">一个 API 地址，一部手机，让 Codex 随时可用。</p>

在这里完成 API 配置，或者把电脑上的 Codex 接到手机。

## 选择服务

### API 中转

适合已经安装 Codex、只需要配置 API 地址和 API Key 的场景。你可以在控制台创建密钥、复制当前版本的 Codex 配置，并在仪表盘查看用量。

[开始配置 API 中转 →](/relay/)

### 手机远程控制

电脑不在身边，也能从手机继续操作 Codex。

[开始使用手机远程控制 →](/agents-anywhere/)

::: warning 重要提示
API Key、配对 Token 和远程终端都具有较高权限。只在可信设备上使用，不要把密钥或配对命令发到公开渠道。
:::
