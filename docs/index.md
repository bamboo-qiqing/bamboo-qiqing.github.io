# 两颗枣树

面向 AI 工具和远程开发设备的服务文档。

这里提供两类服务的操作指南：通过 API 中转使用 Codex，以及从浏览器或手机控制自己设备上的 Codex。

<div class="actions">

  <a class="action secondary" href="/agents-anywhere/">连接远程设备</a>
</div>

## 选择服务

### API 中转

适合已经安装 Codex、只需要配置 API 地址和 API Key 的场景。你可以在控制台创建密钥、复制当前版本的 Codex 配置，并在仪表盘查看用量。

[开始配置 API 中转 →](/relay/)

### 远程 Agent

适合需要离开电脑后继续查看和操作 Codex 的场景。Connector 运行在你的 Windows、macOS 或 Linux 设备上，Web 和 Android 只负责远程控制。

[开始连接远程设备 →](/agents-anywhere/)

::: warning 重要提示
API Key、配对 Token 和远程终端都具有较高权限。只在可信设备上使用，不要把密钥或配对命令发到公开渠道。
:::
