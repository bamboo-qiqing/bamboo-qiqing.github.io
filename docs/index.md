# 两颗枣树

面向 AI 工具和远程开发设备的服务文档。

这里提供两类服务的操作指南：通过 API 中转使用 Codex，以及从手机或浏览器控制自己设备上的 Codex。

<div class="actions">
  <a class="action" href="/relay/">配置 Codex</a>
  <a class="action secondary" href="/agents-anywhere/">手机远程控制</a>
</div>

## 选择服务

### API 中转

适合已经安装 Codex、只需要配置 API 地址和 API Key 的场景。你可以在控制台创建密钥、复制当前版本的 Codex 配置，并在仪表盘查看用量。

[开始配置 API 中转 →](/relay/)

### 手机远程控制

适合离开电脑后继续从手机查看和操作 Codex。被控电脑保持在线后，可以发送消息、处理审批、浏览文件和打开远程终端。

[开始使用手机远程控制 →](/agents-anywhere/)

::: warning 重要提示
API Key、配对 Token 和远程终端都具有较高权限。只在可信设备上使用，不要把密钥或配对命令发到公开渠道。
:::
