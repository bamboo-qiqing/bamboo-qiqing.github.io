# 手机端使用

<p class="doc-intro">打开手机，接着电脑上的 Codex 继续做。</p>

## 安装

1. 从[官方下载页](https://github.com/anywhere-labs/Agents-Anywhere/releases)下载 Android APK。
2. 安装并打开应用。
3. 输入管理员提供的服务地址 `<AGENTS_ANYWHERE_SERVICE_URL>`。
4. 使用已有账号登录。

## 新建任务

1. 打开 **设备**，选择一台在线电脑。
2. 点击 **新建任务**，选择项目文件夹。
3. 输入消息并发送。

之后就可以在手机上继续发消息、处理确认请求、查看文件或打开终端。
