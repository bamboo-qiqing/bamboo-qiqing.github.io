# Android 客户端

## 安装与登录

1. 从 [Agents Anywhere Releases](https://github.com/anywhere-labs/Agents-Anywhere/releases) 下载 Android APK。
2. 在 Android 系统允许安装后打开应用。
3. 输入管理员提供的服务地址 `<AGENTS_ANYWHERE_SERVICE_URL>`。
4. 使用已有账号登录，不要在设备备注或截图中保存密码和 Token。

## 常用操作

- 在 **Devices** 查看在线设备。
- 在 **Active / Archived** 之间切换 Session。
- 打开 Session 发送消息或接管任务。
- 收到审批时查看命令和路径后再决定允许或拒绝。
- 通过 Files 预览工作区文件，通过 Terminal 打开远程终端。

## Android 使用注意

- 手机只是控制端，Codex 仍然运行在 Connector 设备上。
- 设备离线时，手机端不能替代 Connector 执行任务。
- 不要在公共 Wi-Fi 或录屏中暴露远程终端输出。
- 设备丢失时，先在服务端撤销会话或修改账号密码。
