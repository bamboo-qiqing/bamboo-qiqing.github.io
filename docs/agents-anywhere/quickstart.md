# 快速开始

本流程默认你已经拿到服务账号，并且准备控制一台已经安装、登录 Codex 的设备。

## 1. 登录 Web 控制台

打开管理员提供的服务地址：

```text
<AGENTS_ANYWHERE_SERVICE_URL>
```

使用已有账号登录。本文档不包含服务端首次安装、Admin setup token 或账号开通流程。

## 2. 准备被控设备

- 设备可以是 Windows、macOS 或 Linux。
- Codex 已经在该设备上完成本地登录。
- 设备能访问服务端地址。
- 你知道要暴露给 Session 的工作目录。

## 3. 发起配对

在 Web 控制台进入 **Devices → Add device / Pair device**，选择对应平台。页面会生成一次性配对步骤或命令：

1. 只在目标设备执行页面生成的命令。
2. 等待设备出现在在线列表。
3. 检查 Runtime 中是否显示 Codex。
4. 为设备设置容易识别的名称。

不要手动拼接 Connector ID 或 Token。配对命令包含设备授权信息，使用后不要保存到公开脚本。

## 4. 创建第一个 Session

选择在线设备和工作目录，点击 **New session**，发送一个不会修改文件的测试请求：

```text
请确认当前工作目录，并只回复目录名称，不要读取其他文件。
```

确认消息、状态和时间线都能正常刷新后，再开始真实任务。

## 5. 离开电脑后继续处理

设备保持在线时，可以从 Web 或 Android 查看 Session、回复消息、处理审批和观察终端。关闭 Connector 进程会让设备离线，已经运行的任务也可能无法继续同步。
