# 手机远程控制

<p class="doc-intro">电脑不在身边，Codex 也能继续干活。</p>

手机发消息，电脑执行，结果回到手机。就这么简单。

## 只需三步

1. 在电脑上安装并登录 Codex。
2. [安装电脑端](/agents-anywhere/connectors)，按页面提示绑定账号。
3. [打开手机端](/agents-anywhere/android)，选择这台电脑并新建任务。

## 电脑需要保持

- 开机并联网。
- 电脑端正在运行。
- Codex 在电脑上可以正常使用。

::: warning 操作发生在你的电脑上
手机只是遥控器。命令、文件和终端都在电脑上运行，确认内容后再批准操作。
:::
