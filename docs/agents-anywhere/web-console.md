# Web 控制台

## Device

Device 列表显示设备在线状态、Connector 能力和可用 Runtime。设备离线时先检查本地 Connector 进程和网络，不要立即重复配对。

## Session

新建 Session 时选择设备、工作目录和 Codex Runtime。常用操作包括：

- 继续或重新打开已有 Session。
- 置顶常用任务，归档不再活跃的任务。
- 等待长任务完成，或在必要时打断当前回合。
- 使用 Takeover 接管需要人工决策的任务。

## 审批

当 Codex 请求执行高风险操作时，控制台会显示审批。确认命令、路径和影响范围后再允许；不确定时拒绝并要求 Agent 解释。不要为了让任务继续而无条件打开全部权限。

## 文件与终端

文件面板用于浏览、读取、上传和下载工作区内容；终端面板用于一次性命令或交互式 Shell。两者都在 Connector 设备上执行，权限等同于该本地用户。

::: warning 终端输出
终端可能包含环境变量、Token、私钥或项目机密。分享截图前清理完整输出，尤其是 `.env`、SSH 配置和云服务凭据。
:::
