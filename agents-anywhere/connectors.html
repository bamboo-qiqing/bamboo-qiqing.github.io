安装电脑端 ​

在哪台电脑上运行 Codex，就在哪台电脑上安装。下载页面中的 Connector，就是这里说的“电脑端”。

安装前 ​

先在电脑上打开 Codex，确认它可以正常使用；然后登录手机远程控制台。

Windows ​

  1. 从官方下载页下载 Windows 安装包。
  2. 安装并打开电脑端。
  3. 在控制台选择 设备 → 添加设备，按提示完成绑定。
  4. 看到电脑显示“在线”即可。

macOS ​

  1. 从官方下载页选择 Apple Silicon 或 Intel 安装包。
  2. 安装并打开，允许系统要求的网络和文件权限。
  3. 在控制台选择 设备 → 添加设备，按提示完成绑定。
  4. 看到电脑显示“在线”即可。

Linux ​

  1. 在控制台选择 设备 → 添加设备 → Linux。
  2. 复制页面生成的命令，在电脑终端运行。
  3. 保持这个进程运行，看到电脑显示“在线”即可。

不要分享绑定命令

绑定命令里包含设备凭据，只能在自己的电脑上运行。
